**stoub/headlamp-k8s-plugins**
======================

A multi-architecture Docker image for Headlamp k8s Plugins.

**Why this image?**

The image maintained by headlamp team is only build for x86_64. This image is build for various platforms with different architectures (e.g., x86_64, arm64).

**Features**

* Built from the official [Headlamp plugins repository](https://github.com/headlamp-k8s/plugins)
* Multi-architecture support: x86_64, arm64

**Usage**

Refere to the official [Headlamp plugins  repository](https://github.com/headlamp-k8s/plugins)
